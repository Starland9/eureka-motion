# Configuration

`.env` à la racine est chargé par `next.config.ts` et par les scripts ; une variable déjà présente dans le shell l'emporte. Modèle complet : [deploy/.env.example](../deploy/.env.example). Les valeurs ci-dessous sont des exemples fictifs ; aucune clé ne doit être versionnée.

Deepgram : `deepgram` n'est pas dans `TTS_PROVIDERS` par défaut ; `TTS_PROVIDERS=deepgram,pocket` le place devant Pocket. `DEEPGRAM_CONCURRENCY` borne les appels simultanés : un refus 429 ferait passer toute l'explication à la voix suivante. Conditions et licence du service : [docs/licences-voix.md](licences-voix.md#voix-deepgram-aura-2).

Routage des voix : chaque nouvelle explication reçoit la première voix de `TTS_PROVIDERS` qui a encore de la place, puis la garde jusqu'au bout ; une explication compte comme active tant qu'elle a parlé dans les 45 dernières secondes. La dernière voix de la liste n'a pas de limite. Ordre conseillé en production : `TTS_PROVIDERS=deepgram,assemblyai,pocket`.

AssemblyAI : `assemblyai` n'est pas dans `TTS_PROVIDERS` par défaut ; `TTS_PROVIDERS=assemblyai,pocket` le place devant Pocket. `ASSEMBLYAI_PER_MINUTE` borne les départs de requêtes sur toute fenêtre glissante de 60 s : l'offre gratuite en accepte 50 par minute et répond 429 au-delà, ce qui ferait passer toute l'explication à la voix suivante. Conditions et licence du service : [docs/licences-voix.md](licences-voix.md#voix-assemblyai).

Pocket TTS : `pocket` dans `TTS_PROVIDERS` active la voix côté `web`, et `COMPOSE_PROFILES=pocket` démarre le service dans la pile de production ([deploy/README.md](../deploy/README.md#voix-pocket-tts)). Aucune variable ne porte de secret : les poids se téléchargent sans jeton. La mention de crédit à Kyutai s'affiche dans le pied de la page d'accueil quand `pocket` figure dans `TTS_PROVIDERS` ; licences et texte exact dans [docs/licences-voix.md](licences-voix.md).
